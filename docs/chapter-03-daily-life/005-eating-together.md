# Thinking Pattern 005 — Eating Together

## Hindi Thinking Pattern

- खाना तैयार है।
- खाना खा लो।
- थोड़ा और लो।
- पानी पास करना।
- बहुत स्वादिष्ट है।

**Core intention**

Share meals naturally with family.

## Natural English Expressions

| Expression | When to use |
|---|---|
| Dinner's ready. | Call to eat |
| Come and eat. | Invite |
| Would you like some more? | Offer |
| Could you pass the water? | At table |
| This is delicious. | Compliment |

## Memory Tip
Think about the situation first, then choose the simplest natural English.
