# Thinking Pattern 002 — Getting Ready

## Hindi Thinking Pattern

- जल्दी तैयार हो जाओ।
- मेरी शर्ट कहाँ है?
- बैग पैक कर लिया?
- जूते पहन लो।
- चलने का समय हो गया।

**Core intention**

Prepare yourself before leaving home.

## Natural English Expressions

| Expression | When to use |
|---|---|
| I'm getting ready. | General |
| Have you packed your bag? | Before leaving |
| Where's my shirt? | Looking for clothes |
| Let's get going. | Ready to leave |
| I'm almost ready. | Nearly finished |

## Memory Tip
Think about the situation first, then choose the simplest natural English.
