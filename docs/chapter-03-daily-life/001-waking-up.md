# Thinking Pattern 001 — Waking Up

## Hindi Thinking Pattern

- अलार्म बज गया।
- पाँच मिनट और।
- उठना पड़ेगा।
- देर हो रही है।
- आज जल्दी उठना था।
- नींद पूरी नहीं हुई।

**Core intention**

Start your day and react naturally to waking up.

## Natural English Expressions

| Expression | When to use |
|---|---|
| My alarm just went off. | Alarm rings |
| I need five more minutes. | Want more sleep |
| I'd better get up. | Need to get out of bed |
| I'm running late. | Overslept |
| I'm wide awake now. | Fully awake |

## Memory Tip
Think about the situation first, then choose the simplest natural English.
