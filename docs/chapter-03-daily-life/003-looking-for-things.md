# Thinking Pattern 003 — Looking for Things

## Hindi Thinking Pattern

- मेरी चाबी कहाँ है?
- फोन देखा?
- मेरा बटुआ नहीं मिल रहा।
- चार्जर कहाँ रखा है?
- मिल गया!

**Core intention**

Find everyday personal items.

## Natural English Expressions

| Expression | When to use |
|---|---|
| Have you seen my keys? | Keys |
| I can't find my wallet. | Wallet |
| Where did I leave my phone? | Phone |
| Found it! | Located item |
| It was right here. | Misplaced item |

## Memory Tip
Think about the situation first, then choose the simplest natural English.
