# Thinking Pattern 004 — Cooking

## Hindi Thinking Pattern

- चाय बना दूँ?
- खाना बन रहा है।
- गैस बंद कर देना।
- सब्ज़ी काट दो।
- नमक देना।

**Core intention**

Prepare food and coordinate in the kitchen.

## Natural English Expressions

| Expression | When to use |
|---|---|
| I'll make some tea. | Offer |
| Dinner's almost ready. | Cooking |
| Could you turn off the stove? | Safety |
| Can you chop the vegetables? | Help |
| Pass me the salt, please. | Dining |

## Memory Tip
Think about the situation first, then choose the simplest natural English.
